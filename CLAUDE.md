# Проект: сайт-магазин флісового костюма «Теплий Затишок»

Одностраничный магазин одного товара (лендинг с заказом). Аудитория: украинские женщины, размеры 50–60. Язык сайта: украинский. С владельцем общаемся по-русски.

## Структура
- `site/index.html`: весь сайт в одном файле (HTML + CSS + JS), без сборки
- `site/img/`: фото `{цвет}-{1..3}.jpg`, миниатюры `{цвет}-{1..3}-t.jpg`, отзывы `review-{1..4}.jpg`
- `content/product.md`: все тексты, цены, размеры, шаги заказа (источник правды для копирайта)
- Корень проекта = папка `сайт`. В ней же лежит исходный Telegram-экспорт (не трогать): `messages.html`, `photos\` (оригиналы фото 1024×1536), `css\`, `js\`, `images\` (служебные файлы экспорта)
- `shop\`: ранняя копия сайта, дубль `site\`; рабочая версия только `site\`

## Как смотреть
Открыть `site/index.html` в браузере или запустить `npx serve site`.

## Настройки в начале `<script>` в index.html
- `CONFIG.ORDER_ENDPOINT`: адрес приёма заявок (POST, JSON: product, color, size, price, name, phone, createdAt). Пока пусто: форма в демо-режиме и честно пишет, что заявка не отправлена.
- `CONFIG.PROMO_END`: конец акции (ISO-дата). Пусто: конец текущих суток. Скидка должна реально заканчиваться вместе с таймером.
- `COLORS`, `SIZES`: цвета и размеры (имена файлов фото = `id` цвета).

## Дизайн
Шрифты: Unbounded (заголовки, цены) + Onest (текст). Акцент: красный бренда. Страница подкрашивается цветом выбранного костюма (`--sel`). Светлая и тёмная темы через токены в `:root`. Мобильная версия обязательна (липкая кнопка «Замовити»).

## Правила
- Не выдумывать факты о товаре, цены, отзывы и контакты: брать только из `content/product.md` или спрашивать владельца.
- Отзывы на сайте это реальные скриншоты переписки, их не подменять.
- Держать сайт одним файлом без сборки, пока владелец не попросит иначе.
